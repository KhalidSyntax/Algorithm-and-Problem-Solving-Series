# 🧮 Algorithm and Problem Solving – Level 1, 2, 3 & 4

This repository contains beginner-to-advanced problem-solving tasks using **C++**.
It is part of a structured learning path focused on:

✅ Logical thinking
✅ Clean modular code
✅ Step-by-step problem solving
✅ Real-world algorithms

---

## 📘 Level 1 – Basics

### 🔍 Summary

* Builds a strong foundation in C++ programming.
* All problems solved using functions for clean code and readability.
* Covers the basics of:

  * Input / Output
  * Variables & datatypes
  * Arithmetic operations
  * Conditions
  * Loops (`for`, `while`, `do-while`)
* The goal is to develop logical thinking and error-free coding.

### 🛠 Language

* C++

### 📁 Structure

Each `.cpp` file solves a specific problem and is named accordingly
(e.g., `Problem-1.cpp`, `Problem-2.cpp`, ...).

## 📕 Level 4 – Dates, Calendars & Time

### 🔍 Summary

* Introduces real-world algorithms used in scheduling systems, calendars, and time calculations.

* Teaches how to build reusable functions for date manipulation.

* Topics include:

  * Number to Text conversion
  * Leap Year detection
  * Number of Days / Hours / Minutes / Seconds in a Month or Year
  * Day name of a given date
  * Month calendar / Year calendar
  * Day order inside the year
  * Convert day-order back to date
  * Add Days / Weeks / Months / Years / Decades / Centuries / Millennium
  * Find the difference between two dates (positive or negative)
  * Calculate age in days

* Uses:
  ✅ Functions
  ✅ Struct for date operations
  ✅ Modular design
  ✅ System date reading

### 🛠 Language

* C++

### 📁 Structure

Each `.cpp` file is focused on one problem and named accordingly, such as:

* `Problem-01.cpp` → Number To Text
* `Problem-02.cpp` → Leap Year
* `Problem-07.cpp` → Day Name
* `Problem-08.cpp` → Month Calendar
* `Problem-09.cpp` → Year Calendar
* `Problem-12.cpp` → Add Days To Date
* `Problem-18.cpp` → Age In Days
* `Problem-19.cpp` → Difference In Days
* `Problem-20-to-32.cpp` → Increase date by days, weeks, months, years, decades…
